# Godot Community MCP Proof Harness (SBL-MCP-003)

This directory provides a minimal, self-contained, reproducible proof harness for the community Model Context Protocol (MCP) adapter `@coding-solo/godot-mcp` evaluated against standard Godot 4.7.2 Stable.

## Governance & Isolation Context

Per `AGENTS.md` (§ AI Game Developer MCP caution):
> "Before using AI Game Dev to manipulate Godot, demonstrate a Godot-compatible MCP/adapter on a disposable project: list scene tree, create/edit node, save scene, inspect errors, run headless validation, and collect evidence. If unsupported, use Godot-native files/headless CLI and record the integration as pending. Never install a Unity package into Godot or invent equivalent Godot tools."

**Production Isolation Rule**: SoulBound's core production workflow remains native GDScript and headless CLI suites (`tests/headless/*.gd`). MCP adapters are strictly evaluated and proven on isolated disposable projects located outside the repository (e.g., in `$env:TEMP`). No `node_modules`, credentials, or vendored binaries are tracked in this repository.

---

## Directory Contents

| File | Purpose |
|---|---|
| `run_adapter_proof.js` | Node.js driver script that spawns the MCP server via stdio, dispatches JSON-RPC requests, and triggers headless engine validation. |
| `mcp_generated_scene.tscn` | Reference copy of the Godot 4 scene generated by the MCP server during the empirical run. |
| `verify_mcp_scene.gd` | Godot 4.7.2 GDScript headless verification suite asserting root node type, player node, and collision shape. |
| `README.md` | Reproduction guide, exact CLI invocations, and observed output. |

## Prerequisites

- Node.js >= 18.0.0 (`node --version`, `npx --version`)
- Godot 4.7.2 Stable console binary (`Godot_v4.7.2-stable_win64_console.exe` or `godot` in system PATH)

## Reproduction Instructions

### 1. Automated Execution (Recommended)

Run the proof driver directly:

```powershell
node tools/mcp-proof/run_adapter_proof.js
```

Or specify custom paths if your Godot binary or disposable project directory differs:

```powershell
node tools/mcp-proof/run_adapter_proof.js --godot-path "C:\Path\To\Godot_v4.7.2-stable_win64_console.exe" --project-path "$env:TEMP\disposable_godot_mcp_proof"
```

The driver automatically scaffolds the minimal `project.godot` in the external directory, connects via stdio, runs all tool calls, updates the reference scene, and executes headless Godot verification.

### 2. Manual Step-by-Step Reproduction

If you wish to run each step manually:

#### A. Scaffold Disposable Project
```powershell
$target = Join-Path $env:TEMP "disposable_godot_mcp_proof"
New-Item -ItemType Directory -Path $target -Force
Set-Content -Path (Join-Path $target "project.godot") -Value @"
; Engine configuration file
config_version=5
[application]
config/name="Disposable Godot MCP Proof"
config/features=PackedStringArray("4.7", "Forward Plus")
"@
Copy-Item "tools/mcp-proof/verify_mcp_scene.gd" -Destination $target
```

#### B. Launch MCP Server
```powershell
$env:GODOT_PATH = "C:\Users\ALCOHOL\Downloads\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe"
npx --yes @coding-solo/godot-mcp
```

Send the JSON-RPC tool calls over stdio:
1. `initialize`
2. `tools/call` `get_godot_version` -> returns `4.7.2.stable.official.ed1daf0bf`
3. `tools/call` `get_project_info`
4. `tools/call` `create_scene` (`scenePath: "mcp_generated_scene.tscn"`, `rootNodeType: "Node2D"`)
5. `tools/call` `add_node` (`nodeType: "CharacterBody2D"`, `nodeName: "Player"`)
6. `tools/call` `add_node` (`nodeType: "CollisionShape2D"`, `nodeName: "Collider"`, `parentNodePath: "Player"`)
7. `tools/call` `save_scene` (`scenePath: "mcp_generated_scene.tscn"`)

#### C. Headless Engine Verification
```powershell
$godot = "C:\Users\ALCOHOL\Downloads\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe"
& $godot --headless --path "$env:TEMP\disposable_godot_mcp_proof" --script "res://verify_mcp_scene.gd" --quit-after 60
```
